## 1. Python 基础学习

### Python 文件运行流程

理解 Python 文件需要通过 Python 解释器执行。

执行流程：

Python文件(.py)

↓

Python解释器

↓

执行代码

↓

终端输出结果

理解 VS Code 的运行功能本质也是调用 Python 解释器执行文件。

------------------------------------------------------------------------

### 输入输出

学习：

`input()`

作用：

获取用户输入。

理解：

`input()` 返回的数据默认是字符串。

例如：

``` python
age = input()
```

输入：

    18

实际：

``` python
age = "18"
```

------------------------------------------------------------------------

`print()`

作用：

将结果输出到终端。

------------------------------------------------------------------------

### 变量和数据类型

理解：

变量用于保存数据。

例如：

``` python
name = "cici"
```

变量：

name

保存：

"cici"

学习：

不同数据类型会影响程序处理方式。

如果需要进行数学计算，需要类型转换：

``` python
age = int(input())
```

------------------------------------------------------------------------

### 字符串处理

学习：

字符串可以使用 `+` 进行拼接。

例如：

``` python
"Hello " + name
```

同时了解 Python 推荐使用 f-string：

``` python
f"Hello {name}"
```

因为代码更加清晰。

## 3. Prompt 设计学习

今天学习 Prompt 基础结构：

高质量 Prompt：

人设（Role）

-   

背景（Context）

-   

要求（Task）

-   

限制（Constraint）

-   

输出格式（Output Format）

### 人设

告诉 AI 扮演什么角色。

例如：

Python导师、AI架构师。

### 背景

告诉 AI：

-   当前学习阶段
-   项目背景
-   目标

### 要求

明确 AI 需要完成什么任务。

### 限制

控制 AI 输出范围。

例如：

-   不直接修改代码
-   不使用超出当前阶段的高级知识

### 输出格式

规定 AI 返回结果结构。

------------------------------------------------------------------------

今天形成新的 AI 使用流程：

任务目标

↓

设计 Prompt

↓

AI执行

↓

人工判断

↓

优化结果

理解：

Prompt 不是简单提问，而是将人的需求转换成 AI 可以理解和执行的任务描述。

## 4. Git / GitHub 工程实践

复习 Git 工作流程：

修改文件

↓

git status

↓

git diff

↓

git add

↓

git commit

↓

git push

理解：

### git status

查看当前仓库状态。

### git diff

查看修改前后的具体变化。

### git add 文件名

将指定文件修改加入暂存区。

### git add .

将当前目录及子目录中的修改、新增、删除变化加入暂存区。

### git commit

保存一个版本。

### git push

上传到 GitHub。
