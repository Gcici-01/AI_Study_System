# 一、Python 主线学习记录

## 1. List（列表）

### 1.1 List是什么

List 是 Python 中一种用于存储多个数据的数据结构。

特点：

- 可以保存多个元素
- 元素具有顺序
- 可以通过索引访问
- 可以动态添加和删除元素


示例：

```python
tasks = [
    "Learn Python",
    "Practice Git",
    "Study AI"
]
```

数据结构：

```
tasks

 |
 |-- Learn Python
 |-- Practice Git
 |-- Study AI
```


---

## 1.2 创建List

使用：

```python
[]
```

创建列表。


示例：

```python
names = ["Tom", "Alice", "Bob"]

ages = [18, 20, 30]
```


列表可以存储不同类型的数据：

```python
data = ["Tom", 18, True]
```


---

## 1.3 List索引访问

Python列表索引从0开始。


例如：

```python
tasks = ["Python", "Git", "AI"]
```


对应：

```
索引：

0        1      2

Python   Git    AI
```


访问：

```python
tasks[0]
```


结果：

```text
Python
```


---

## 1.4 修改List元素

通过索引修改：

```python
tasks[0] = "Java"
```


修改前：

```python
["Python", "Git", "AI"]
```


修改后：

```python
["Java", "Git", "AI"]
```

## 1.8 list 与 list[str]区别


### list

表示 Python 列表数据类型。


例如：

```python
tasks = []
```


### list[str]

表示类型提示。


例如：

```python
tasks: list[str]
```


含义：

该列表中的元素应该是字符串。


注意：

```python
list[str]
```

不是创建列表。


创建列表：

```python
["Python", "Git"]
```

# 2. for循环


## 2.1 for循环作用

for循环用于：

> 遍历已有的数据集合，对每个元素执行相同操作。


示例：

```python
tasks = ["Python", "Git", "AI"]

for task in tasks:
    print(task)
```


执行过程：

```
第一次：

task = Python


第二次：

task = Git


第三次：

task = AI
```


---

## 2.2 for循环应用场景

适合：

- 遍历列表
- 批量处理数据
- 文件处理
- 文档处理


AI应用场景：

例如：

处理多个文档：

```python
for document in documents:
    process(document)
```


流程：

```
文档1
 ↓
处理

文档2
 ↓
处理

文档3
 ↓
处理
```

# 3. while循环


## 3.1 while作用

while循环用于：

> 当条件满足时重复执行代码。


基本结构：

```python
while 条件:
    执行代码
```


---

## 3.2 while示例

```python
count = 1

while count <= 5:
    print(count)
    count += 1
```


输出：

```
1
2
3
4
5
```


---

# 4. while两种实现方式


## 4.1 条件控制型while


特点：

循环条件直接写在while后面。


示例：

```python
password = input("请输入密码：")

while password != "123456":

    print("密码错误")

    password = input("请输入密码：")

print("登录成功")
```


流程：

```
输入密码

↓

判断密码

↓

错误：
重新输入

↓

正确：
结束循环
```


---

## 4.2 while True + break


特点：

进入无限循环，通过条件主动退出。


示例：

```python
while True:

    password = input("请输入密码：")

    if password == "123456":

        print("登录成功")

        break
```


流程：

```
进入循环

↓

输入

↓

判断

↓

满足条件：

break退出

↓

结束
```


适合：

- 用户交互程序
- 聊天机器人
- 命令行工具


---

# 5. break语句

示例：

```python

    break
```


常用于：

```python

```

循环退出。

## 使用Prompt


角色：

Python导师


背景：

正在学习Python基础，并培养AI应用工程能力。


要求：

分析代码结构、逻辑和问题。


限制：

不要直接修改代码。

先提供：

- 问题分析
- 优化建议


输出格式：

1.代码结构分析

2.做得好的地方

3.存在的问题

4.优化建议

5.知识点总结


---

## 使用过程中发现的问题


AI分析结果不能完全直接接受。


需要判断：

- 代码是否错误
- 是否符合需求
- 是否符合最佳实践


例如：

代码没有满足某个默认需求，

不一定代表代码逻辑错误。
